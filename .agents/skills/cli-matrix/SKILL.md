# Матрица загрузок

## Изоляция
```sh
export VD_LIBRARY_DIR=$PWD/.sprint/cli-lib VD_WORK_DIR=$PWD/.sprint/cli-work
```
- Библиотеку пользователя, его сервер :8765 и установленную выдру не трогать. Свой сервер — :8797.
- Запись в Windows — только в `/mnt/c/Users/Ihor/Downloads/vydra-matrix/`, после проверки удалить.
- На диске одновременно не больше 5 ГБ: длительность и кодеки записал — большой файл удалил.

## Оси
- **Платформы.** YouTube: обычное, shorts, длинное (1 ч+ — только MP3 или отрезок), доступное в 4K, с возрастным
  ограничением, приватное или удалённое, прямой эфир, плейлист. TikTok: видео, фото-слайдшоу. Instagram: reel,
  карусель с несколькими видео, закрытый аккаунт (cookies). Другие сайты: Vimeo, X, Reddit, клип Twitch,
  SoundCloud (только звук).
- **Формат и качество.** mp4 / mp3 / both; best, 1080, 720, 480, 360 (где есть); mp3 128 / 192 / 320.
- **Отрезок.** Начало–конец в `м:сс`, `ч:мм:сс` и секундах; только начало; только конец; за пределами длины;
  нулевой и перевёрнутый.
- **Ссылки.** Три за раз, одна из них плохая; из буфера обмена; с `&` и `?` без кавычек (должна быть подсказка);
  мусор вместо ссылки; сайт без поддержки.
- **Названия.** Эмодзи, кавычки, слэши, двоеточия, очень длинные, одинаковые (без перезаписи). Кириллица — не приоритет,
  но не ломать.
- **Куда.** Папка по умолчанию, `-o` в папку с пробелами, `/mnt/c/...`, несуществующая папка.
- **Среда.** TTY и пайп (`| cat`), машинный вывод (если есть), Ctrl+C посреди загрузки (в папке без мусора),
  повтор после обрыва сети.

## Ссылки
Стабильные — из `tests/test_live.py`, дополняй туда же. Где брать новые: поле `_TESTS` у экстракторов yt-dlp
(`yt_dlp/extractor/<сайт>.py`); ресёрч — `agy -p` (без правок).

## Проверка каждого случая
Код выхода; понятен ли человеку вывод (прогресс, итог, ошибка с подсказкой); файл на месте и с разумным именем;
`ffprobe`: длительность (отрезок ±1 с), кодеки (mp4 — h264/aac, mp3 — mp3), разрешение; в папке нет `.part`,
`.ytdl` и временных файлов.

## Запись — docs/cli/MATRIX.md
Таблица «№ | платформа | ролик | параметры | ожидалось | получилось | статус | коммит или причина».
Статусы: `OK`; `FIX` — был баг, исправлен (коммит + тест); `SITE` — сбой на стороне сайта или сети (повторить через
5 минут и записать оба результата); `KNOWN` — ограничение, которое вывод объясняет пользователю.

## macOS
Здесь не проверить — только код и тесты с моками: `open -R`, `pbpaste`, `~/Downloads`, нет `wslpath` и
`powershell.exe`. Любое ветвление по платформе — одной функцией в `vydra/system.py` с тестом на каждую ветку.
