# Спринт выдры: дирижёр

Ты дирижёр. Код сам почти не пишешь: запускаешь этапы, проверяешь итог, отмечаешь цели, коммитишь, докладываешь.
Твой контекст — для картины целиком: не читай большие файлы и отчёты агентов, если хватает итогового JSON этапа.
Вызов этого скилла — явное согласие пользователя на мультиагентный запуск: этапы идут через инструмент Workflow.
План и роли — `docs/AI-WORKFLOW.md`, цели — `docs/sprint/GOALS.md`.

## 0. Где мы — каждый раз
```sh
python3 tools/sprint.py status
```
Следующий этап, жив ли CLI-трек, подняты ли серверы, предупреждения хуков. Всё состояние в файлах, поэтому после
`/clear` просто вызови `/ui-sprint` снова.

## 1. Цель сессии — один раз
Если `/goal` ещё не задан, предложи его инструментом ProposeGoal (пользователь подтверждает одним нажатием):

> Спринт выдры завершён: последняя строка вывода `python3 tools/sprint.py status` в разговоре — `SPRINT: ALL DONE`,
> после чего сделан локальный коммит; или дирижёр написал пользователю, что упёрся в решение, которое может принять только он.

Перед концом каждого своего хода запускай `python3 tools/sprint.py status`: по этому выводу проверяющий `/goal`
видит прогресс.

## 2. Подготовка — в начале и если что-то упало
- Сервер dev :8799 и Edge CDP :9333 — скиллы `dev-server` и `ui-rig` (запуск в фоне, проверка `curl`).
- **CLI-трек** — если `status` говорит, что он не запущен или молчит дольше 20 минут:
  ```
  Agent(subagent_type: "vydra-cli", isolation: "worktree", description: "CLI выдры для WSL и macOS",
        prompt: "Цели C1–C4 в docs/sprint/GOALS.md; порядок работы — в твоём описании агента.")
  ```
  Перезапуск после обрыва — в промпт добавь: «прошлый агент работал в ветке <ветка>: начни с
  `git merge --ff-only <ветка>`, прочитай docs/cli/PROGRESS.md и продолжай с места остановки».
  Затем `git worktree list` → `python3 tools/sprint.py cli <ветка> <id агента> <путь>`.
  Трек идёт параллельно до выпуска; его отчёт придёт уведомлением — отметь C1–C4 по доказательствам, но не мёржи до S5.

## 3. Этап
| Этап | Перед запуском | Воркфлоу | Цели |
|---|---|---|---|
| S0 стенд и контракт | `python3 tools/sprint.py begin s0` | `vydra-s0-rig` | G1 G2 G3 |
| S1 направление | `begin s1` | `vydra-s1-direction` | G4 |
| S2 фундамент | `begin s2` | `vydra-s2-foundation` | G5 |
| S3 регионы | `begin s3` — замораживает фундамент, включает параллельный режим | `vydra-s3-regions` | G6 |
| S4 приёмка | `begin s4` | `vydra-s4-accept` | G7–G13 |
| S5 выпуск | `begin s5` | — скилл `ship` | G14, C1–C4 |

```
Workflow({name: "<воркфлоу>", args: {notes: "<замечания пользователя, если были>"}})
```
Воркфлоу идёт в фоне. Закончи ход (status — последним), не опрашивай его в цикле; пока ждёшь — отвечай пользователю.
Дополнительные `args`: `rounds` (кругов ревью, по умолчанию 2), `regions` (S3: только перечисленные регионы).
Лишних кругов сверх `rounds` не добавляй: ревью `vydra-designer` (Opus 5.5, max) — самые дорогие вызовы спринта.

## 4. Этап вернулся
1. Итоговый JSON: `ok` и ключевые поля. `ok: false` — пойми по полям, что именно не так, прежде чем что-то делать.
2. Проверь сам одно-два главных доказательства дёшево: открой через Read один лист-контакт или кадр, не все.
3. Отметь цели в `docs/sprint/GOALS.md`: `[x]` и в строке `↳` — путь к отчёту, кадру или выводу. Не подтверждено —
   не отмечай.
4. После S3 — `python3 tools/sprint.py end`. Вернулись `foundation_notes` — один агент `vydra-ui` (Agent tool)
   «правки фундамента» с этими замечаниями и прогоном стенда. `api_bugs` любого этапа — SendMessage агенту CLI-трека
   (это его зона); сам бэкенд не чини.
5. Коммит локально: `git add vydra/static tools docs .claude .agents AGENTS.md HANDOFF.md` → сообщение по-русски
   «UI S<n>: …», без атрибуции ассистента. `.sprint/` не коммитится.
6. Пользователю 3–5 строк: что готово, что нет, путь к листу-контакту. **После S1 обязательно покажи кадр первого
   экрана** (`hero_shot`) — это главное решение спринта. Замечания пользователя передай в `args.notes` следующего этапа.
7. Следующий этап — сразу, подтверждения не жди.

## 5. Если что-то пошло не так
- Этап оборвался (лимит, сбой): `Workflow({scriptPath: <путь из результата>, resumeFromRunId: <runId>})` —
  готовые агенты вернутся из кэша.
- Этап вернул `ok: false` после всех кругов: не перезапускай вслепую. Точечный агент нужного типа (Agent tool)
  на конкретные замечания или короткий вопрос пользователю.
- Предупреждения хуков (`gate-warnings.log`, `hook-errors.log`) показывает `status`. Хук блокирует по ошибке —
  исправь хук, а не обходи его.
- Пользователь пишет «пауза» — закончи текущий шаг, обнови `HANDOFF.md` и остановись; цель он снимет `/goal clear`.

## 6. S5 — выпуск
Скилл `ship`.
