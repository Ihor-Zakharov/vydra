# Проход по региону

## Карта и владение
Регионы, их CSS-файлы, секции разметки и JS, состояния стенда — в `docs/sprint/REGIONS.md`.
- **Свой CSS-файл** региона — правишь свободно.
- **Общие файлы** — `index.html`, `app.js`, `explorer.js`, `sw.js` — только инструментом Edit и только в своих
  секциях (разметка своего региона; блоки `app.js` под заголовками своего региона). Перед каждой правкой — свежий
  Read нужного фрагмента: файл меняют и другие. Write по общим файлам на этапе регионов хук не пропустит.
- **Фундамент** — `css/core.css`, `css/shell.css`, `cosmos.js`, `spring.js` — на этапе регионов (S3) заморожен.
  Нужен новый токен — локальная переменная в своём файле (`--jobs-…`) и строка в отчёте (`needs`).
- Бэкенд, `tests/**`, `docs/design/**` — не твои. Баг API — одной строкой в отчёт.

## Цикл
1. Прочитай в `docs/design/DIRECTION.md` раздел своего региона целиком, общие разделы (токены, сетка, типографика,
   движение) и чек-лист приёмки своего региона. Свои строки в `docs/sprint/FEATURES.md` — это контракт.
2. «До»: `python3 tools/ui_rig.py --label <метка>-0 --states <свои> --viewports s,l --jobs 2` → лист-контакт через Read.
3. Правь маленькими сериями (одно состояние или один компонент). После каждой серии — стенд на затронутые состояния
   и Read кадров. Смотри не только «похоже ли на DIRECTION», но и на выравнивание краёв, ритм отступов, переносы,
   обрезку, наведение и фокус, стыки с соседними регионами.
4. Правил JS — пройди свои строки FEATURES.md, которые мог задеть (действиями на стенде или коротким сценарием
   Playwright).
5. Самопроверка перед отчётом:
   - стенд на **все** свои состояния в окнах s, m, l (для героя и xl): по твоим кадрам в `report.json` — 0 ошибок
     консоли, 0 вылетов, 0 обрезанного текста, 0 нарушений axe serious/critical;
   - нет отладочного кода, закомментированных кусков, `!important` без причины, чисел мимо токенов (кроме тех, что
     прямо заданы в DIRECTION);
   - каждое решение, которого нет в DIRECTION, записано в `decisions`.
   Хук `SubagentStop` не отпустит тебя, если после последней правки `vydra/static` не было прогона стенда.
6. Отчёт по схеме вызывающего воркфлоу; `shots` — папка последнего полного прогона.

## Мир — напоминание, не замена DIRECTION
KOCMOC / KOCMOC UNLEASHED: монохром, цвет только в излучении, раскалённо-белый горизонт событий, мягкое свечение,
движение без рывков, монументальный масштаб. Своё не придумывай — решения в DIRECTION.
