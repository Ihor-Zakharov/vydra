# Передача на сопровождение (2026-09-25)

## Что это
Выдра — загрузчик видео (YouTube / TikTok / Instagram / ~1800 сайтов) с веб-интерфейсом и консолью.
Python 3.13 + uv, FastAPI, yt-dlp, ffmpeg. Установка и команды — `README.md`. Правила проекта — `AGENTS.md`.

## Как работать
- Запуск из исходников: `uv run vydra ui`. Тесты: `uv run pytest -q` (быстрые), `uv run pytest -m live` (сеть).
- Интерфейс: `vydra/static/**`, тёмная тема «чёрная дыра» (KOCMOC / UNLEASHED), только ПК. Направление дизайна —
  `docs/design/DIRECTION.md`, эталон сцены и прототипы — `docs/archive/sprint/`.
- Стенд интерфейса (скриншоты всех состояний): `python3 tools/ui_rig.py` (скилл `ui-rig`, серверы — скилл `dev-server`).
- AI-воркфлоу: агенты `.claude/agents/`, скиллы `.agents/skills/`, этапы спринта `.claude/workflows/`, хуки зон
  `.claude/hooks/`, план — `docs/AI-WORKFLOW.md`, цели — `docs/sprint/GOALS.md`, статус — `python3 tools/sprint.py status`.

## Сделано в последней сессии

  ссылки, без прокрутки на окнах от 1280×600 до 2560×1300 (в т. ч. масштаб 125/150 %).
- «Очередь» и «Библиотека» по центру, подвал внизу окна, постраничный вывод (50 задач / 120 файлов на страницу).

- Сцена глубже на 25 %, звёзды с параллаксом; новая иконка приложения; README на английском.

## Известные проблемы (не сделано)
- **Круги сцены со временем пропадают** (или в отдельных сценариях). Не исправлено. Незаконченная попытка —
  `docs/archive/sprint/notes/rings-wip.patch` (не применять вслепую). Подозрения: точность float32 при большом времени
  в шейдере (`cosmos.js`, uT/_t/_age), облегчённый режим не возвращает слои, NaN после сна/скрытой вкладки,
  потеря WebGL-контекста.
- `vydra update` на нативной Windows сломан (ищет `env/bin/python`, заблокированные файлы). Пока — обновлять
  повторным запуском команды установки. Идея: передавать обновление `install.ps1` в новом окне после выхода выдры.
- Не проверено вживую: PowerShell 7, ARM64, GPO AllSigned / ConstrainedLanguage, корпоративный HTTPS-прокси
  (yt-dlp берёт только certifi), блокировки Defender. Возможно нестабильны тесты
  `test_external_programs_never_read_the_terminal`, `test_cancel_while_waiting_for_retry`.
- Спринт: открыты G6–G14 (`docs/sprint/GOALS.md`); DIRECTION §7.2/§7.4 устарели после решений пользователя
  (окно «Параметры», постраничный вывод, центрирование экранов).
