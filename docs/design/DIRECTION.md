# Направление интерфейса выдры — «Затмение на месте»

Тёмная тема, только ПК (окна `s` 1366×657, `m` 1536×730 @1.25, `l` 1920×960, `xl` 2560×1305). Мир — KOCMOC / KOCMOC UNLEASHED.
Автор решений — `vydra-designer` (S1, 2026-09-25). Функции не меняются: контракт — `docs/sprint/FEATURES.md`, состояния — `docs/sprint/STATES.md`.
Светлые правила в CSS не трогать и не удалять, переключатель темы скрыт.

**Тезис.** Чёрная дыра — сцена, поле ссылки — герой: монохромная бездна, где раскалённое кольцо стоит на световом горизонте справа,
а слева, на чистой тьме, — поле ссылки и единственная раскалённая плита «Скачать»; цвет появляется только как излучение источника ссылки.

## 1. Принципы

1. **Сцена справа, инструмент слева.** Дыра стоит там же и того же размера, что в baseline (решение пользователя); текст и форма — левая колонка на
   затемнении. Текст без подложки живёт только левее 55 % ширины окна. *Никогда:* текст по центру на диске (вариант v1), форма на свету кольца (v3).
2. **Монохром и излучение.** Всё чёрное, белое, серое. Цвет — только свет: кайма кольца, оттенок тумана у кольца, фокус, заливка прогресса, свечение
   ручек отрезка, глиф платформы. *Никогда:* цветные заливки плит и фонов (в том числе оттенок по хешу у обложки без превью `.art` — §7.4.1),
   «неоновые» градиенты на тексте, RGB-расслоение линий интерфейса
   (роковая ошибка «Aggressive Rainbow Chromatic Aberration» — хроматическая аберрация живёт только в кольце сцены).
3. **Ничего резкого.** Переходы — длинные градиенты (сцена → страница за 26svh), края — мягкие, движение — пружины без отскока (damping ≥ 0,8) и
   огибающие без ступенек. *Никогда:* стробоскоп, полноэкранные вспышки, whiteout, тряска, мигание чаще 3 раз в секунду (роковые ошибки
   «Violent Strobe», «Rapid Jitter / Screen-Shake»).
4. **Монументальность — масштабом и пустотой.** Один крупный жест — заголовок-плита (Geologica 800, 70–136 px) и кольцо; всё остальное — тихие
   тёмные плиты. *Никогда:* частицы и обломки на переднем плане, наклоны и вращение камеры, зумы, декоративные «пилы» (роковые ошибки
   «Foreground Debris», «360° Camera Spins», «Pulsing Sawblades»).
5. **Одна раскалённая плита.** «Скачать» — единственный белый объект интерфейса на экране: `#fff`, чёрная подпись, белое свечение. Остальное —
   плиты `#0b0b0e` / `rgba(8,8,10,.78)` с линией 14 %. *Никогда:* второй белый CTA на том же экране (исключение — первичная кнопка внутри
   открытого диалога или карточки вопроса, где «Скачать» не видно или вторично).
6. **Живое, но тихое.** Фон всегда чуть жив (дыхание 7 с ±3 %, дрейф тумана 1,1°/с, пряди у кольца 2,6°/с), курсор чуть гнёт пространство
   (≤ 5 CSS px), событие — один мягкий импульс. *Никогда:* движение, уводящее взгляд от поля ссылки; частицы «в лицо».
7. **Точность чертежа.** Угловые визиры, датумы, кикеры «01 / ССЫЛКА → 02 / ОЧЕРЕДЬ → 03 / ХРАНИЛИЩЕ» на одной левой линии `--datum`,
   моноширинные цифры. *Никогда:* элементы без привязки к сетке, разделы по центру под героем, выровненным влево.

`.sprint/shots/s1c-compare/variants-s.png`, `.sprint/shots/s1c-compare/variants-l.png`.

Что изменено в S1c относительно гибрида S1b (кадры до/после: `.sprint/shots/s1-v4-hybrid/l/idle.png` → `.sprint/shots/s1c-hybrid-all/l/idle.png`):
- туман был практически невидим (`--bh-fog` 1,35 давал разницу с 0 в пределах шума, `s1c-sweep3`) → 2,6, лучи 1 → 1,4: кольцо светит в дымку, видны мягкие лучи;
- рисунок тумана считался в долях высоты окна и на m/s давал два симметричных «уха» над кольцом → считается в долях R, повёрнут на 3 рад (`s1c-fogrot`);
- плоскость-горизонт поднята с 1,45 R до 1,15 R ниже центра: низ ореола уходит в свет плоскости, под линией — отражение кольца («утоплена»);
- «море волн» во всю ширину → пятно света под дырой: линза плоскости ×0,3 (полосы прямые), боковой спад σ = 2,6 R до 28 %;
- пояс ореола был пересвечен в плоский «бублик» → плато 1,55 → 1,05, нити 0,85 → 1,4: видны пряди, внутренняя кромка остаётся раскалённой;
- оттенок источника в тумане был до 55 % → не более 33 % (едва заметный);
- при загрузке сцена ускорялась в 1,6 раза, пряди — в 3,4 → время ×1,3, пряди ×2,1;
- панель при прокрутке была полупрозрачной (сквозь неё просвечивала форма — находка S0) → непрозрачная `#000`;
- заголовок героя «срезался» кромкой панели (preview-trim на s) → растворяется при подходе к панели (привязка к прокрутке);
- разделы и подвал стояли по центру 1240 px, а герой — по левой линии → все на одной линии `--datum`;
- закрытое «Ещё» держало невидимые кнопки битрейта в фокусе и под сценой (format-both: 4 наложения) → `visibility: hidden` после сворачивания.

### 3.4 Стекло и зерно

- Стекла нет: `.glass` = плита (`backdrop-filter: none`, блик за курсором `.glass::before` выключен — функция «блик» в FEATURES остаётся в коде, визуально её нет).
- Размытие фона разрешено только под модальными диалогами и шторками: `::backdrop { background: rgba(0,0,0,.62); backdrop-filter: blur(8px) }`.
- Зерно: слой `.grain` поверх сцены и под контентом, `opacity: .045`, **статичное** (без смены кадров — мерцание зерна = микростробоскоп).
  Внутри сцены свой дизеринг ±1,5/255 (шейдер), против полос в градиентах.

### 3.5 Сетка и отступы

- Шкала: **4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96**. Другие значения — только оптические поправки ±1–2 px с комментарием.
- `--datum: max(24px, 7.5vw)` → s 102, m 115, l 144, xl 192 px. Левая кромка колонки героя, заголовков разделов, содержимого разделов и подвала.
- Разделы: `max-width: calc(1632px + 2 * var(--datum))`, `padding-inline: var(--datum)`, `margin: 0` (прижаты влево), `padding-top: clamp(56px, 8svh, 96px)`.
  Ширина содержимого: s 1162, m 1306, l 1632, xl 1632 (справа остаётся 736 px — на xl это продолжение композиции героя).
- Рамка сцены (визиры, панель, показания): 24 px от краёв окна.
- Ритм внутри формы: лид → вкладки `max(22px, 3.8svh)`; вкладки → поле 16; поле → превью 12; поле/превью → ряд форматов 12; ряд → «Ещё»-содержимое 16; строки «Ещё» 12.
- Карточки: внутренний отступ 12 (превью 10), зазор колонок 16, зазор между карточками 12; заголовок раздела → содержимое 24.
- Панель: высота `--topbar-h: 56px`, `scroll-padding-top: calc(var(--topbar-h) + 16px)`.

### 4.2 Ступенчатость и наложение

- Первая загрузка: кикер 0 ms → тонкая строка 60 → слово-плита 120 → лид 180 → вкладки 240 → поле 300 → ряд форматов 360; каждый `enter()` (dy 14, blur 8).
  Поле ссылки интерактивно сразу (фокус не ждёт анимации). Сцена открывается параллельно: экспозиция 0 → 1 за 1,4 с (smoothstep, квадрат) —
  сначала фотонное кольцо, затем ореол и туман (`.sprint/shots/s1c-motion/l/m00-open-*.png`).
- Правило наложения: второй элемент стартует на 60–80 % хода первого; одновременный старт более чем двух элементов запрещён.
- Доводка с инерцией: подпись следует за своим объектом с задержкой 60 ms и оседает на 200 ms позже (например, процент у полосы).

### 4.5 Reduced motion и `?motion=0`

- Сцена: один кадр во «время постера» t = 14 с; нет течения времени, параллакса, линзы курсора, импульсов, открытия-экспозиции; оттенок и энергия
  применяются мгновенно; `pulse()` ничего не делает; перерисовка — только при изменении размера, оттенка или прокрутки.
- Пружины — `snap()` (уже в `spring.js`); `enter()/exit()` без смещения и размытия; мигающие точки, дыхание дорожки, вращение каймы, неопределённый
  прогресс — статичны (неопределённый: сегмент 28 % ширины при прозрачности 35 %); эквалайзер аудио — статичные столбики разной высоты.
- Привязка к прокрутке (растворение строк героя, угасание показаний и визиров) — **не движение во времени и остаётся** и при reduced-motion, и при
  `.motion-off`: в `core.css` правило `.motion-off *` должно её не гасить (в черновике — переопределения с `!important`, §0).
- `scroll-behavior: auto`; view transitions — 10 ms.

## 5. Сцена (`cosmos.js`)

### 5.1 Композиция — положение и размер baseline

`baseLayout(vw, vh)` из черновика — формула baseline (`app.js: heroLayout` + высота героя baseline), в CSS px холста (холст = `100svh` первого экрана):

```
heroH = max(674, 0.94·vh);   k = clamp(0.115·vw/1440, 0.09, 0.14)
cx = 0.70·vw;   cy = 68 + heroH/2;   R = k·heroH          (R — радиус тени; ореол виден до ≈ 1,35 R)
```

Это решение пользователя; менять нельзя ни на одном окне. Высота холста не зависит от роста героя (превью, «Ещё»): дыра — неподвижный ориентир.

### 5.4 Скорость (цель G9)

- Разрешение холста: 0,5 от CSS px (`devicePixelRatio` ограничен 1), не больше 1,1 Мпикс (xl: 1280×652).
- Кадры: 30 fps в покое; 60 fps, пока двигается курсор (0,5 с после последнего `pointermove`) и во время импульса.
- Пауза: вкладка скрыта (`visibilitychange`), герой вне экрана (`IntersectionObserver`, порог 0), прокрутка > 100svh; reduced-motion — перерисовка по событию.
- Никакой работы в главном потоке длиннее 4 ms на кадр (uniform + один `drawArrays`); текстура декодируется `img.decoding = 'async'`.

### 5.5 API (S2 переносит без изменений сигнатур)

`createCosmos(canvas, { reduced, seed = 0.37, resScale = 0.5 })` →
`{ ok, setAccent(hex, amt = 1), setPointer(x, y), setScroll(v), setEnergy(v), pulse('go' | 'done'), pause(), resume(), resize(), readTokens(), destroy() }`.
Вызовы из `app.js`: распознана платформа → `setAccent(--el-a)`, снята → `setAccent(null)`; отправка → `pulse('go')`; остров `compact/expanded` →
`setEnergy(1)`, `ask` → `setEnergy(0.4)`, иначе `setEnergy(0)`; остров `done` → `pulse('done')`.
