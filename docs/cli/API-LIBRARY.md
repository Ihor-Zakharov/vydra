# Хранилище: постраничная выдача, итоги, ссылка на оригинал, смена папки — контракт API

Для интерфейса (пагинация, поиск, сортировка, «открыть оригинал», перенос хранилища) и фикстур стенда.
Все изменения — **только дополнения**: без новых параметров ответы те же, что раньше.

## Элемент хранилища (файл)

```json
{
  "id": "3f9c1a2b4d5e", "path": "YouTube/Видео/Клип.mp4", "type": "video", "title": "Клип",
  "platform": "youtube", "size": 10485760, "added": 1790323547.3,
  "source": "https://www.youtube.com/watch?v=jNQXAC9IVRw",
  "uploader": "jawed", "duration": 19.0, "width": 320, "height": 240,
  "poster": ".vydra/posters/3f9c1a2b4d5e.jpg", "clip": [60.0, 300.0], "probed": true,
  "folder": "YouTube/Видео", "name": "Клип.mp4"
}
```

- `source` — ссылка на оригинал (страница ролика), **есть у каждого элемента**: строка или `null`.
  У скачанного выдрой — сразу. У найденного сканированием (скачан другой копией выдры, до переустановки,
  перенесён руками) — восстанавливается **в фоне** из тега `comment`, который выдра пишет в каждый MP4/MP3
  (заодно и `title` из тега `title`, если название было просто именем файла). Пока фон не дошёл до файла —
  `null`; когда дошёл — придёт событие `library` с новой `rev`. Свои файлы (конвертер) — `null` навсегда.
- `probed` — метаданные файла уже прочитаны (служебное; для интерфейса не нужно). Новое поле.
- `duration`, `width`, `height`, `poster` — тоже дозаполняются в фоне (как раньше).
- Открыть оригинал: в браузере по `source` (`<a href target="_blank" rel="noopener">`); консоль —
  `vydra open --source <часть названия>`.

## GET /api/library

Без параметров — **как раньше**: весь список, новые сверху.

```json
{"root": "C:\\Users\\Ihor\\Downloads\\VideoDownloader", "stats": {…}, "items": [ …все файлы… ], "rev": 1790323547123}
```

С любым из параметров — постранично:

| Параметр | Значения | По умолчанию |
|---|---|---|
| `limit` | 1…1000 — размер страницы | все (без ограничения) |
| `offset` | ≥ 0 | 0 |
| `sort` | `added` · `name` · `size` · `duration` | `added` |
| `order` | `asc` · `desc` | `desc`; для `name` — `asc` (А→Я) |
| `q` | поиск: все слова, без учёта регистра, по названию и имени файла | — |
| `type` | `video` · `audio` | оба |
| `folder` | папка хранилища (`"TikTok/Видео"`, `""` — корень): только её прямые файлы | все папки |

`duration`: файлы без длительности — всегда в конце. Неверные значения — `422`.

```
GET /api/library?limit=50&offset=0&sort=size&q=космос&type=video
```
```json
{
  "root": "C:\\Users\\Ihor\\Downloads\\VideoDownloader",
  "stats": {"count": 50000, "videos": 29882, "audios": 20118, "size": 10005554013265,
            "size_by_type": {"video": 5979334870112, "audio": 4026219143153}},
  "rev": 1790323547123,
  "items": [ …до 50 элементов… ],
  "total": 8061,
  "offset": 0,
  "limit": 50,
  "next_offset": 50
}
```

- `total` — сколько подходит под `q`/`type`/`folder` (для «стр. 3 из 162»); `stats` — итоги **всего** хранилища.
- `next_offset` — `null` на последней странице.
- Страницы устойчивы, пока не сменилась `rev`: сменилась — перезапросите текущую страницу.

## GET /api/library/stats — итоги без списка

```json
{"stats": {"count": 50000, "videos": 29882, "audios": 20118, "size": 10005554013265,
           "size_by_type": {"video": 5979334870112, "audio": 4026219143153}},
 "rev": 1790323547123, "root": "C:\\Users\\Ihor\\Downloads\\VideoDownloader"}
```
Мгновенно (итоги считаются один раз на ревизию). Для счётчиков в шапке вместо полного `/api/library`.

## GET /api/fs?path=…

Без новых параметров — как раньше (все подпапки и **все** файлы папки). С любым из `limit`, `offset`, `sort`,
`order`, `q`, `type` — файлы постранично (подпапки — всегда все), плюс поля:

```json
{"path": "YouTube/Видео", "name": "Видео", "breadcrumbs": […], "folders": […], "rev": 1790323547123,
 "files": [ …страница… ], "files_total": 4474, "offset": 0, "limit": 50, "next_offset": 50}
```

`folders[].count` и `.size` — рекурсивные итоги папки (как раньше).

## Когда перечитывать: SSE `/api/events`

`event: library` / `data: {"rev": N}` — только номер ревизии, без данных (так было и раньше). На событие —
перезапросить текущую страницу (или `/api/library/stats`), а не весь список. События приходят при изменениях
в Проводнике/Finder (наблюдатель сверяет только изменившиеся папки), после загрузок и пачками по мере
фонового заполнения длительностей, постеров и `source` (не чаще раза в 10 с).

## Смена папки хранилища

### POST /api/settings/library

| Тело | Что делает |
|---|---|
| `{"path": "D:\\Видео"}` | переключиться на папку (файлы остаются в прежней; прежняя запоминается) |
| `{"reset": true}` | переключиться на папку по умолчанию («Загрузки»/VideoDownloader) |
| `{"path": "D:\\Видео", "move": true}` | перенести хранилище в `path` и переключиться; **если `path` уже текущая** (её только что выбрали) — перенести в неё содержимое **прежней** папки |
| `{"reset": true, "move": true}` | то же для папки по умолчанию |

Ответ — как `GET /api/settings`; при `move` ещё
`"moved": {"bytes": 10485760, "total": 10485760, "renamed": 1, "added": 0}` (`renamed` — сколько файлов получили
« (2)» из-за совпадения имён).

Ошибки (`detail` — готовый текст для человека): `400` — та же папка, новая внутри текущей, нет прав на запись,
«Переносить нечего: прежней папки с файлами нет», «Перенос уже идёт»; `409` — папка задана `VD_LIBRARY_DIR` или
прежняя папка недоступна (диск отключён).

Перенос: только то, что принадлежит хранилищу (отделы платформ, папки с медиа, медиа из корня, `.vydra` с индексом
и постерами); чужие файлы остаются. На одном диске — переименование (мгновенно), между дисками — копия, сверка
размера, удаление исходника. Совпадения имён — « (2)». Оборвался (выключили, диск отвалился) — повторный POST
доделает: уже скопированное не дублируется. Загрузки во время переноса ждут его конца. id, постеры, отрезки и
`source` сохраняются.

### GET /api/settings/library/move — ход переноса

POST с `move` отвечает, когда перенос закончен (большие папки между дисками — минуты). Пока он идёт, можно
опрашивать:

```json
{"active": true, "done": 5242880, "total": 10485760, "name": "YouTube/Видео/Клип.mp4",
 "from": "C:\\Users\\Ihor\\Downloads\\VideoDownloader", "to": "D:\\Видео", "error": null, "result": null}
```
После конца: `"active": false` и `result` (как `moved`) или `error`.

### Консоль

```sh
vydra settings --storage "D:\Видео" --move      # выдра настройки --папка "D:\Видео" --перенести
vydra settings --storage-reset                  # вернуть папку по умолчанию (--папка-сброс)
vydra folder "D:\Видео" --move                  # то же, старая команда
vydra list --page 2 --limit 50 --sort size --search "космос" --folder "TikTok/Видео" --json
vydra open --source "часть названия"            # открыть оригинал в браузере (выдра показать --оригинал)
```
