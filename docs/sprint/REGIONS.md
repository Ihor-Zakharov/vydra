# Регионы интерфейса — кто что правит

Страница поделена на регионы, чтобы исполнители работали параллельно, не мешая друг другу (этап S3).
CSS разносится по этой карте на этапе S0 (`vydra-mech`), он же уточняет её селекторами по факту разноса.
Секции `app.js` — по заголовкам-комментариям `/* ===== … ===== */`.

| Регион | CSS | Разметка `index.html` | JS | Состояния (`STATES.md`) |
|---|---|---|---|---|
| **фундамент** (S2) | `css/core.css` — токены, база, стекло, зерно, кнопки, появление, view transitions, reduced motion; `css/shell.css` — верхняя панель, сцена героя и заголовок, заголовки разделов, подвал, «сервер недоступен», тосты | `<header class="topbar">`, `<footer class="foot">`, контейнер и заголовок `.hero`, заголовки `.section` | `app.js`: тема, стекло, космос, «чернила», тосты, сервер недоступен, клавиши, общее; `cosmos.js`; `spring.js` | `idle`, `offline`, `toast-*` |
| **hero** — форма | `css/hero.css` — вкладки, поле ссылки, «Вставить», «Скачать», форматы, «Ещё», «Сохранять в», превью, отрезок, конвертер | органы формы внутри `.hero` (консоль ссылки, превью, конвертер) | `app.js`: вкладки; формат, качество, отрезок, папка назначения; портал ссылок; превью ссылки; конвертер | `typing-*`, `multi-links`, `preview-*`, `format-*`, `controls-open`, `dest-menu`, `converter`, `converter-drag` |
| **jobs** — загрузки | `css/jobs.css` — остров, очередь, карточки задач, карточка вопроса | `<section class="queue">`, разметка острова | `app.js`: очередь, Dynamic Island, показания | `job-*`, `jobs-many` |
| **library** — хранилище | `css/library.css` — папки, крошки, дерево, плитки и список, поиск, выделение, перетаскивание файлов | `<section class="library">` | `explorer.js` целиком | `library-*`, `explorer-tree` |
| **dialogs** — диалоги | `css/dialogs.css` — диалоги, плеер, шторки, модальные окна | все `<dialog>` | `app.js`: плеер, шторки и модальные окна, настройки, состояние системы | `player`, `settings`, `health-*`, `folder-dialog`, `confirm`, `cheats` |

Правила владения — в скилле `region-pass`. Коротко: свой CSS-файл — свободно; общие файлы — только Edit и только
свои секции; на S3 фундамент заморожен (хук); новый общий токен — через отчёт, решает арт-директор.

## Разнос по факту (S0, `vydra-mech`)

CSS разнесён построчно (не по выборочным селекторам) — цельные секции исходного `styles.css` легли в свои файлы
как есть, поэтому составные правила вида `.a, .b, .c` из разных регионов не дублировались, а остались в файле
того региона, где были в исходнике:
- `.job-badge, .pv-badge, .tile-pf` (кружок-бейдж иконки платформы) — целиком в `jobs.css`; `hero.css` (превью)
  и `library.css` (плитка) используют его без переопределения размеров.
- `.tile-dur, .pv-dur` — целиком в `library.css` по той же причине.
- `.art` (обложка без превью — волна/цвет по хешу) и `.empty` (пустое хранилище) — в `library.css`, хотя `.art`
  переиспользуется в `hero.css` (превью ссылки) и `dialogs.css` (плеер, аудио-обложка); правило универсально и не
  зависит от порядка файлов.
- `.dragveil` / `.dragveil-folder` (оверлей при перетаскивании файлов ОС над окном) — решил положить в
  `library.css`: назначение overlay — конвертация в хранилище и подсветка папки хранилища. Не в DIRECTION —
  нейтральное техническое решение, не дизайнерское; если арт-директор захочет иначе — переносится один класс.
- `@media (prefers-reduced-motion: reduce)` был одним правилом на 7 селекторов всех регионов — разложен на
  5 отдельных правил (по одному в `core.css`, `shell.css`, `hero.css`, `jobs.css`, `dialogs.css`), каждое с тем
  же `animation: none !important` на своих селекторах. Проверено построчным сравнением с `baseline` — эффект тот
  же.
- Адаптивные `@media (max-width: …)` блоки были едиными на всю страницу — каждое правило ушло в конец файла
  своего региона (порядок между файлами не влияет на результат: пересекающихся по specificity селекторов между
  регионами нет, кроме перечисленных выше составных правил, которые не резались).
- Порядок файлов в `index.html`/`sw.js`: `core → shell → hero → jobs → library → dialogs` — совпадает с порядком
  таблицы выше.

Проверка эквивалентности: построчный парсер сравнил исходный `styles.css` и новые 6 файлов как множества правил
(с учётом `@media`-условий) — разница ровно в 2 удалённых мёртвых правилах и разбиении reduced-motion, без потерь
и дублей. Стенд `--label split --diff baseline` — см. отчёт спринта.
