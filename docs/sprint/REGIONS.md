# Регионы интерфейса — кто что правит

Страница поделена на регионы, чтобы исполнители работали параллельно, не мешая друг другу (этап S3).
CSS разносится по этой карте на этапе S0 (`vydra-mech`), он же уточняет её селекторами по факту разноса.
Секции `app.js` — по заголовкам-комментариям `/* ===== … ===== */`.

| Регион | CSS | Разметка `index.html` | JS | Состояния (`STATES.md`) |
|---|---|---|---|---|
| **фундамент** (S2) | `css/core.css` — токены, база, стекло, зерно, кнопки, появление, view transitions, reduced motion; `css/shell.css` — верхняя панель, сцена героя и заголовок, заголовки разделов, подвал, «сервер недоступен», тосты | `<header class="topbar">`, `<footer class="foot">`, контейнер и заголовок `.hero`, заголовки `.section` | `app.js`: тема, стекло, космос, «чернила», тосты, сервер недоступен, клавиши, общее; `cosmos.js`; `spring.js` | `idle`, `offline`, `toast-*` |
| **hero** — форма | `css/hero.css` — вкладки, поле ссылки, «Вставить», «Скачать», форматы, «Ещё», «Сохранять в», превью, отрезок, конвертер | органы формы внутри `.hero` (консоль ссылки, превью, конвертер) | `app.js`: вкладки; формат, качество, отрезок, папка назначения; портал ссылок; превью ссылки; конвертер | `typing-*`, `multi-links`, `preview-*`, `format-*`, `controls-open`, `dest-menu`, `converter`, `converter-drag` |
| **jobs** — загрузки | `css/jobs.css` — остров, очередь, карточки задач, карточка вопроса | `<section class="queue">`, разметка острова | `app.js`: очередь, Dynamic Island, показания | `job-*`, `jobs-many` |
| **library** — хранилище | `css/library.css` — папки, крошки, дерево, плитки и список, поиск, выделение, перетаскивание файлов | `<section class="library">` | `explorer.js` целиком | `library-*`, `explorer-tree` |
| **dialogs** — диалоги | `css/dialogs.css` — диалоги, плеер, шторки, модальные окна | все `<dialog>` | `app.js`: плеер, шторки и модальные окна, настройки, состояние системы | `player`, `settings`, `health-*`, `folder-dialog`, `confirm`, `cheats` |

Правила владения — в скилле `region-pass`. Коротко: свой CSS-файл — свободно; общие файлы — только Edit и только
свои секции; на S3 фундамент заморожен (хук); новый общий токен — через отчёт, решает арт-директор.
