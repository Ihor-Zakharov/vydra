# Контракт функций интерфейса — аудит S0

Составлено чтением `vydra/static/index.html`, `app.js`, `explorer.js` (без правок). Регионы — как в
`docs/sprint/REGIONS.md`. Состояния — идентификаторы из `docs/sprint/STATES.md` (после дополнения этим аудитом).
Строки без запроса к API — чисто клиентские функции (localStorage, DOM).

## События SSE (`/api/events`)

| событие | обработчик | эффект |
|---|---|---|
| `open` | `events.ok = true` | дальше живая синхронизация вместо поллинга (`pollRev` перестаёт дёргать API) |
| `library` | debounce 250 мс → `explorer.refresh()` | обновление хранилища + мигающий индикатор `#sync` |
| `jobs` | немедленный `pollJobs()` | ускоренное обновление очереди без ожидания текущего интервала |
| `error` (закрытие соединения) | закрыть `EventSource`, `events.ok = false` | откат на резервный `pollRev` раз в 10 с |

## Тосты (сводно по типам и источникам)

`toast(message, type, {timeout, action})` — `ok`/`err`/`info`/`warn`; максимум 4 одновременно; с `timeout:0` висит,
пока не закрыт явно (`.close()`), с `action` — кнопка внутри тоста. Источники: результат закачки/загрузки файла,
ошибки API (закачка, конвертация, файловые операции), сеть недоступна, изменения настроек (папка, cookies, авто-режимы),
предупреждения (папка назначения исчезла, «формат недоступен — взял ближайший»), успех операций с файлами (удаление,
перемещение, переименование, создание папки).

## Подсказки (title / aria-label, не покрытые выше)

Кнопки формата/качества у слайдера показывают причину недоступности («В этом видео такого качества нет»);
`#autostart-wrap`/`#auto-accept-wrap` — заголовок объясняет эффект переключателя; кнопки плеера и файлов задач —
подписи действия ( «Открыть файл в вашем плеере», «Показать файл в Проводнике» и т. п.); `#dest-btn` — меняющаяся
подсказка в зависимости от того, задана ли своя папка.
