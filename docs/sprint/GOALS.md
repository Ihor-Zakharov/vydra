# Цели спринта (Definition of Done)

Спринт = UI-трек (этапы S0–S5, по очереди) + CLI-трек (параллельно, агент `vydra-cli` в своём worktree).
Статус одной командой: `python3 tools/sprint.py status` — её последнюю строку (`SPRINT: ALL DONE` /
`SPRINT: OPEN n`) проверяет `/goal`.

Отмечать `[x]` может только дирижёр (хук не даёт субагентам править этот файл) и только с доказательством:
путь к отчёту, кадру, коммиту или выводу команды — в строке `↳`. Отметить без доказательства — нарушение.
Окна стенда: `s` 1366×657, `m` 1536×730 (dpr 1.25), `l` 1920×960, `xl` 2560×1305. Только ПК, только тёмная тема.
