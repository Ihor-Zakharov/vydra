# AI-воркфлоу: довести выдру за одну сессию

Главная сессия (Opus) — дирижёр: раздаёт задачи, сводит отчёты, мёржит worktree, коммитит и пушит.
Сама она код почти не пишет, её контекст нужен, чтобы держать картину целиком.

| Агент | Модель | Зона | Когда |
|---|---|---|---|
| `vydra-wsl` | Opus | `vydra/*.py`, `install.*`, `tests/**` | фаза 1, параллельно с UI |
| `vydra-ui` | Sonnet | `vydra/static/**` | фаза 1, параллельно с WSL |
| `vydra-designer` | Fable | `vydra/static/**` | фаза 2, когда UI уже работает |
| `vydra-qa` | Haiku | только читает | после каждой фазы |
| `agy` (Gemini Flash) | — | только отвечает, без правок | ресёрч по ходу |

## Фазы

**0. Разогрев (5 мин, дирижёр).** `git pull`, `uv sync`, `uv run pytest -q`, поднять сервер на 8799.
Параллельно ресёрч для `agy`:
```
agy --add-dir ~/projects/video-downloader -p='Что сломалось в yt-dlp за последний месяц для YouTube, TikTok и Instagram (issues, релизы, нужные флаги или cookies)? Сверь с vydra/downloader.py и дай короткий список рисков со ссылками.'
```

**1. Работает (параллельно, каждый в своём worktree).**
- `vydra-wsl`: зависание `vydra ui` без вывода → сервер на 8765 не отвечает → «показать в папке» → смена хранилища → повторная установка.
- `vydra-ui`: 7 сценариев из своего промпта, скриншоты на каждый.
- Дирижёр: API-баги из отчёта UI передаёт в `vydra-wsl`, мёржит обе ветки, гоняет `vydra-qa`.
- Коммит + пуш, как только QA зелёный. Это точка «друг может обновиться».

**2. Красиво (последовательно).** `vydra-designer` работает на смёрженном main: тёмная тема «чёрная дыра».
Функциональные баги из его отчёта уходят обратно к `vydra-ui`. Потом `vydra-qa` → коммит → пуш.

**3. Потом (если останется время, по приоритетам из HANDOFF).** Консоль «до ума» (русские флаги,
ссылка из буфера, вопросы в CLI), CI. **Светлая тема — самой последней.**

## Промпт для старта сессии

Вставить в новую сессию Claude Code, открытую в `~/projects/video-downloader`:

```
Прочитай AGENTS.md, HANDOFF.md и docs/AI-WORKFLOW.md. Ты дирижёр, сам код почти не пишешь.
Сегодня за одну сессию доводим выдру по фазам из AI-WORKFLOW.md.
Фаза 0 — сам. Фаза 1 — запусти параллельно vydra-wsl и vydra-ui, каждого с isolation: worktree,
и agy для ресёрча yt-dlp. Сведи отчёты, баги API из отчёта UI передай vydra-wsl, смёржи, прогони vydra-qa.
QA зелёный — коммит и пуш. Фаза 2 — vydra-designer на main, потом vydra-qa, коммит, пуш.
После каждой фазы — короткий отчёт мне: что готово, что нет, ссылка на скриншоты.
Не спрашивай подтверждений на коммит и пуш в main этого репо. Светлую тему не трогать.
```
