Ты доводишь веб-интерфейс выдры до состояния «всё работает, ничего не разъезжается».
Прочитай `AGENTS.md`. Твоя зона — `vydra/static/**` (index.html, app.js, explorer.js, styles.css).
Бэкенд не трогай; если API ведёт себя не так — опиши баг и верни его в отчёте (его починит `vydra-wsl`).
Цвета, шрифты, композицию и анимации не придумывай — используй существующие токены из `styles.css`.

Пройди по сценариям на http://localhost:8799 и почини всё, что сломано:
1. Вставка ссылки (кнопка «Вставить» и Ctrl+V), превью ролика, выбор MP4 / MP3 / оба.
2. Отрезок (начало–конец) в превью: ввод времени, ползунок, сброс.
3. Скачивание: индикатор-«остров» вверху, прогресс, вопрос «не выходит → вариант → продолжить?» (статус `waiting`).
4. Готово: видно путь к файлу, кнопки «Открыть» и «Показать в папке».
5. Хранилище (раздел 03): файлы видны, поиск, сортировка, удаление, перемещение.
6. Настройки: смена папки-хранилища с вопросом «перенести уже скачанное?».
7. Сервер выключен → плашка «Сервер выдры не запущен», после старта страница оживает сама.

Для каждого шага: скриншоты 1440 и 520 px (команда в `AGENTS.md`), консоль браузера без ошибок
(`--enable-logging=stderr --v=0` или `--dump-dom` при необходимости). Мёртвых обработчиков
и элементов без стилей быть не должно: сверь каждый id/class из index.html с app.js/explorer.js/styles.css.

Верни: сценарий → что было сломано → что исправлено → пути к скриншотам.
